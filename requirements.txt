# Dependencies for the Hugging Face Space, which installs with pip rather than uv.
# `pyproject.toml` + `uv.lock` remain the source of truth for the project, the Docker
# image and CI; this file exists only because a Space cannot use them.
#
# DELIBERATELY UNPINNED, and this is not laziness. A Space installs its own
# `gradio[oauth,mcp]==<sdk_version>` alongside whatever is listed here, and gradio
# constrains several packages we also depend on. An exact-pinned export of `uv.lock`
# makes that unsatisfiable — verified:
#
#   gradio 6.26.0 depends on pydantic>=2.11.10,<=2.12.5
#   you require pydantic==2.13.5
#   -> No solution found when resolving dependencies
#
# So this lists only the DIRECT dependencies from `pyproject.toml`, at the same
# constraints, and lets pip resolve the overlap with gradio. The consequence, stated
# rather than discovered later: the Space may run slightly different transitive versions
# than `uv.lock` produces locally. The suite is run against the resolved set before
# publishing for exactly that reason.
#
# `gradio` and `uvicorn` are absent on purpose — the Space installs both itself, and
# listing them here lets pip resolve a second, conflicting copy over the top.
